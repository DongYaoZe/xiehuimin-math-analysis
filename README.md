# 《数学分析习题课讲义（第2版）》LaTeX 整理与习题解答

这是谢惠民、恽自求、易法槐、钱定边《数学分析习题课讲义（第2版）》的数字化整理项目。题面以 2018 年上册、2019 年下册扫描版为依据，希望把这套经典讲义做成一份更适合电脑、平板和打印阅读的版本，也给自学和复习时查题、看解答提供方便。

当前 v1.0 共 1512 页，完整排入第 1 至 26 章正文。全书整理出 1523 个练习、思考题和参考题单元，每道题后面都直接接上对应解答，读题以后不必再翻到书末或另一册寻找答案。我私下把它叫作“谢惠民的方便面”，因为一直想做一份拿来就能查、就能读、就能对答案的版本，拖了很久，这次总算做出来了。

## 1512 页的“谢惠民的方便面”

很早以前我就想把这套书完整整理一遍。当时网上比较容易遇到的习题解答主要有两套。一套通常署名“顺数人”，只做到上册，但曾经免费分享；另一套常被称作“甲乙版”，覆盖范围更广。我当时能接触到的公开资料里，甲乙版流传出来的多是部分内容，完整版本据当时的说明主要以带购买者身份信息水印的纸质形式提供，获取门槛很高。

这些资料都很有价值，也各有局限。顺数人的解答比较容易获得，却只有上册；甲乙版能补上更多题目，但完整内容不便检索和查阅。我一直想要一份从题面到解答都完整、可以全文搜索、还能不断修订的版本。AI 工具成熟以后，这件事终于有了现实的做法。

这套版本先用 AI 辅助把上下册正文和题面逐章整理成结构化 LaTeX，再让 AI 在不依赖流传答案的前提下逐题作答。初稿完成后，再拿“顺数人”和“甲乙”两套解答逐题交叉复核。遇到更简洁、更漂亮或更有启发性的做法，就吸收到正式解答里；遇到结论或过程冲突，则重新推导判断。流传答案在这里主要用来校对和提供启发。最终文字来自独立作答、交叉复核和重新推导，没有直接照录任何一套答案。

## 项目特色

- **原题与解答放在一起**  每道题后紧接解答，适合连续阅读，也方便做题后马上核对。
- **尽量忠实于原书**  正文和题面以扫描版为依据，保留原书章节次序、公式和主要结构，发现原书或转录疑点时优先回看扫描页。
- **解答经过多轮复核**  先独立作答，再用现有解答材料检查，好的另解会被吸收到正式版本中。
- **数学记号统一**  微分算子、常用常数、函数名和公式格式统一处理，减少扫描版和不同解答来源之间的记号跳动。
- **按书籍方式重新排版**  章节、定理、例题、练习和解答有清楚的视觉层级。长公式、目录页码和跨页题解也做过专门调整，长时间阅读会比逐页扫描更轻松。
- **配图尽量保留原书味道**  需要题图时优先从原书扫描页裁取和清理，不用 AI 重画来替代原图。
- **可以搜索，也可以继续修改**  PDF 适合直接阅读和全文检索，LaTeX 源码同时公开，发现错字、公式问题或更好的解法都可以继续修订。

## 怎样阅读

想直接看成书版本，可以到 [Releases](https://github.com/DongYaoZe/xiehuimin-math-analysis/releases) 下载最新 PDF。v1.0 已将上下册合并成一部连续的 26 章讲义，解答就在原题下面。

如果你只想查某一题，可以直接在 PDF 中搜索题号、关键词或公式附近的文字。想核对转录来源、参与勘误或调整排版，则可以查看仓库里的 LaTeX 源码和页级来源记录。

## 当前范围

第 1 至 26 章正文和对应题解已经完整纳入正式版。原书前言、参考题提示、参考文献、索引等少量前后置材料仍有部分没有完全转录，因此这个项目目前更适合作为正文阅读版和习题解答版使用。

解答经过多轮检查，但一千多道题的项目仍可能留下笔误或值得改进的地方。发现问题欢迎提交 Issue，并尽量附上题号、页码或你的推导。
